1. QR Code Reporting
Passengers can scan QR code to report dangerous situations.

2. Lock Screen Shortcut
Passengers can quickly report emergencies using a lock screen shortcut.

3. Silent Reporting
Passengers can report harassment or violence without speaking.

4. Staff Alerts
The application aims to send alerts to train staff within 30 seconds.

5. Repeated Report Limit
The application limits repeated reports from the same device to prevent miss alerts.
