MVP Scope & Feature Backlog

The Ultimate Product Vision
I want to create a train safety alert application for train passengers. This app helps passengers report dangerous situations, such as harassment or violence, without speaking.

The Launch Goal (v1.0 MVP)
I plan to release a test version in November 2028.

Feature Prioritization Matrix
Must Have (MVP Lineup):
QR Code Reporting: Passengers can scan a QR code to report dangerous situations. This makes reporting easy.
Silent Reporting: Passengers can report dangerous situations without speaking. This helps passengers stay safe.
Staff Alerts: The app sends alerts to train staff quickly. This helps staff respond to dangerous situations.
Nice to Have (Post-Launch Backlog):
Lock Screen Shortcut: Passengers can report emergencies from their lock screen. This is useful, but passengers can use QR codes first.
Repeated Report Limit: The app limits repeated reports from the same device. This can be added later to reduce false alerts.
